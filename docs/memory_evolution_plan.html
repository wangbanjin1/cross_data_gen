跨会话长程记忆认知架构演进：指标体系、工作记忆检索与经验记忆构造规划

方案概述：针对数据集向多层记忆体系跃迁的核心需求，系统性规划：交互效率评测指标体系（冷启动多轮澄清 vs 热启动轮次压缩 TCG）、工作记忆（基于“这次/上周/昨天”相对时态的工单记录检索），以及经验记忆（基于情境反思的避坑知识库与智能体主动建议）。以下提供完整框图、数学公式定义与工程实施路线。

架构全景与演进背景

当前项目已完成 150 个画像（2,100 会话、3,960 轮交互）的基线数据生成，全面实现了基于“长期偏好与个性化表达”的语义记忆闭环，保持 100% 质检通过率。

在与实际业务与人类交互质感的对齐中，单一的“老规矩偏好”无法满足多层认知需求：

  • 缺乏冷热启动的交互效率对比标尺：智能体在“无记忆”时必须多轮澄清、防范脑补；在“有记忆”时应大幅压缩交互，缺少量化指标；
  • 缺少基于时间与单据引用的工作记忆：真实用户极少死板背诵参数，而是高频使用“这次还按上周的来”、“把昨天的改一下”，需要对历史流水账进行时态关联检索；
  • 缺少情境避坑的最佳实践经验记忆：面对复杂现场环境（如暴雨、大型漫展高密人流），智能体需要调取历史反思沉淀的经验策略，并能主动向用户提议。

交互指标两条线

在数据构造与评测体系中，必须建立清晰可量化的评估标尺。系统以冷启动无记忆多轮澄清与热启动有记忆轮次极速压缩作为两条对照主线：

  • 主线一（冷启动无记忆多轮澄清线）：用户首次发起业务时，智能体严禁脑补参数或默认开通。首轮未提供关键槽位时必须精准反问澄清，严格保证交互轮数不少于 2 轮（典型为 2~3 轮），完成“用户发起 →\to→ 客服反问澄清 →\to→ 用户补全并确认 →\to→ 客服受理收尾”的完整闭环，参数早泄率与擅自默认率必须为 0.0%；
  • 主线二（热启动有记忆轮次极速压缩线）：智能体已沉淀相应语义偏好或唤醒历史工单时，准确命中记忆槽位并直接向用户反问确认，交互轮次收敛至 1~2 轮，免去繁琐基础参数盘问，实现极速闭环。

核心评测指标公式

指标一：交互轮数压缩增益 (Turn Compression Gain, TCG)

用于衡量长程记忆机制为用户带来的交互轮次效率提升比率：

LaTeX · TCG 公式
TCG=Tˉcold−TˉhotTˉcold\text{TCG} = \frac{\bar{T}_{\text{cold}} - \bar{T}_{\text{hot}}}{\bar{T}_{\text{cold}}}TCG=Tˉcold​Tˉcold​−Tˉhot​​

其中：

  • Tˉcold\bar{T}_{\text{cold}}Tˉcold​ 表示无记忆冷启动会话的平均交互轮数（理论基准：2.5∼3.02.5 \sim 3.02.5∼3.0 轮）；
  • Tˉhot\bar{T}_{\text{hot}}Tˉhot​ 表示有记忆热启动会话的平均交互轮数（理论基准：1.0∼2.01.0 \sim 2.01.0∼2.0 轮）；
  • 基准目标：TCG≥35%∼50%\text{TCG} \ge 35\% \sim 50\%TCG≥35%∼50%。
指标二：零记忆澄清完整率 (Cold-Start Clarification Rate, CSCR)

衡量智能体在无先验记忆时的抗幻觉与规范反问能力：

LaTeX · CSCR 公式
CSCR=Nvalid_clarificationNcold_sessions×100%\text{CSCR} = \frac{N_{\text{valid\_clarification}}}{N_{\text{cold\_sessions}}} \times 100\%CSCR=Ncold_sessions​Nvalid_clarification​​×100%

首轮缺少画质/时延/时长等关键通信槽位时，智能体动作必须包含 Clarify_Slot 或 Request_Info，且严禁提前私自默认开通。目标达标线：100.0%。

指标三：工作记忆单据检索准确率 (Episodic Record Retrieval Accuracy, ERRA)

衡量用户使用时态相对代词时，模型在历史工单流水账中定位目标单据的准确率：

LaTeX · ERRA 公式
ERRA=Ncorrect_record_retrievedNrelative_time_sessions×100%\text{ERRA} = \frac{N_{\text{correct\_record\_retrieved}}}{N_{\text{relative\_time\_sessions}}} \times 100\%ERRA=Nrelative_time_sessions​Ncorrect_record_retrieved​​×100%

提取的历史单据 ID 与参数继承准确率必须与标注真值严格一致。目标达标线：100.0%。

指标四：经验记忆情境激活与采纳率 (Experiential Memory Trigger & Acceptance Rate, EMTAR)

衡量在特定外场困难情境下，智能体经验建议被合理触发并被用户采纳的比例：

LaTeX · EMTAR 公式
EMTAR=Naccepted_experience_suggestionsNexperience_trigger_contexts×100%\text{EMTAR} = \frac{N_{\text{accepted\_experience\_suggestions}}}{N_{\text{experience\_trigger\_contexts}}} \times 100\%EMTAR=Nexperience_trigger_contexts​Naccepted_experience_suggestions​​×100%

在识别到特定现场外部挑战（如人流高密拥塞、恶劣天气弱网丢包）时，智能体经验提议命中并被用户确认采纳的比例。目标达标线：≥ 90.0%。

工作记忆工单账本检索

时态相对指称计算与检索逻辑

系统根据当前会话的基准时间 reference_time，动态计算与历史各工单单据的时间差 Δt\Delta tΔt，并构建精准自然的口语指代：

  • Δt=1\Delta t = 1Δt=1 天：映射为“昨天”或“昨天的那个保障”；
  • Δt=2\Delta t = 2Δt=2 天：映射为“前天”；
  • 3≤Δt≤73 \le \Delta t \le 73≤Δt≤7 天：映射为“上周”或“上周同期的保障”；
  • 同类型最近一条记录：映射为“上次”或“上回在[地点]办的那个”。

两种交互通路范例

通路一：智能体主动经验提议 (T2-9 Proactive Suggestion)

[User 1]：“今晚去工人体育场做现场赛事转播，帮我开启保障。”

[Agent 1]：“已为您准备赛事转播保障。根据此前大型场馆人流高密的避坑经验，当时将画质调整为 720p、时延锁定在 30ms 以内有效避免了拥塞卡顿。今晚是否直接采纳这一经验配置？”

[User 2]：“采纳，就按这个避坑方案开吧，稳妥第一。”

[Agent 2]：“已为您开启 720p/30ms 经验保障，预祝转播顺利！”

通路二：用户主动调取经验 (T2-10 Empirical Recall)

[User 1]：“今天山上又是大暴雨，上次你在恶劣天气帮我怎么调的来着？直接按上次那套方案来。”

[Agent 1]：“上次暴雨现场为您采用了增强抗丢包方案（720p 高清、30ms 极低时延）。已为您调取该经验方案，时间从 15:00 到 17:00，确认开启吗？”

[User 2]：“对，直接开。”

[Agent 2]：“抗恶劣天气经验保障已生效！”

四阶段工程迭代路线

Phase 1 · 1~2 天
指标体系与规范设计
确立 TCG、CSCR、ERRA 离线统计指标公式；定义工作记忆账本与经验知识库的 JSON Schema 标准规范。
Phase 2 · 2~3 天
工作记忆工单流水落地
升级 MemoryTracker 记录工单；实现时态推断器；落地 T2-6/T2-7/T2-8 模板，验证 20 个画像原型。
Phase 3 · 2~3 天
经验记忆主动提议落地
结合职业扩充外场避坑经验池；落地 T2-9 主动提议与 T2-10 经验回溯；优化自然语言台词质感。
Phase 4 · 1~2 天
质检套件与 Benchmark
扩展 qc_validator.py 质检规则；发布离线评测评估工具；输出全量 TCG 效率增益分析与评测报告。

验证与验收方案

1. 自动化流水线测试

# 1. 运行单画像原型测试（验证工作记忆工单账本与经验提议）
python run.py --start 0 --count 1 --verify

# 2. 运行多层认知记忆全量单元测试
python -m unittest discover tests

# 3. 运行自动化 Benchmark 离线评估脚本，输出 TCG 与澄清率报告
python scripts/evaluate_memory_benchmark.py --input data/generated

2. 人工抽检验收准则

  • 时态指代严格准确：台词出现“上周”时，目标单据时间严格落在 3~7 天前的历史会话中，杜绝时间错乱；
  • 冷启动零脑补：无记忆会话首轮未提供参数时，智能体 100% 发起反问，无擅自开通；
  • 经验建议自然专业：智能体主动提议符合现场作业逻辑，台词自然诚恳，无生硬 AI 腔调。
