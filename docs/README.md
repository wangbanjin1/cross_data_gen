## 三、 核心技术规范 (Specs)

### 1. [认知记忆全景演进与双轨评测技术规范](specs/cognitive_memory_dev_spec.md) `[最新核心]`
- **业务定位**：专精于“联接”Agent 通信保障场景下的**意图参数提取（提参数）**与高效闭环受理。
- **三层认知记忆架构**：
  - **事实记忆 (Factual Memory)**：用户长期配置画像（偏好、别名映射、长期老规矩）。
  - **工作记忆 (Working Memory)**：跨会话历史工单流水账（单据复用、时间变更、多候选消歧、对账核查）。
  - **经验记忆 (Experiential Memory)**：专家避坑与元认知策略库（ReasoningBank 结构化卡片）。
- **五类金牌经验记忆场景**：
  1. `EXP_MULTI_INTENT_PARTITION_01`：多任务并行局部调整与时序因果隔离。
  2. `EXP_PREWARM_BUFFER_01`：重大活动提前30分钟网络预热起保（时间数学推理）。
  3. `EXP_CALENDAR_HOLIDAY_EXCEPTION_01`：周期例行排期遇法定节假日自动顺延避让。
  4. `EXP_ORDER_QUALITY_DISAMBIGUATION_01`：基于历史工单网络质量日志的智能消歧。
  5. `EXP_OVERLAPPING_ORDER_RESOLUTION_01`：新旧工单时段撞车无缝让路与时序重叠仲裁。
- **会话规模与拓扑**：单生命周期支持 **16 ~ 20 轮动态会话**深度认知演进（S01 ~ S20 动态 DAG 拓扑）。
- **双轨成败分支模拟评测**：
  - 评测 Fast Path（具备经验记忆：1~2 轮极速自闭环）与 Slow Path（缺乏经验记忆：3~5 轮繁琐排查与纠偏）。
  - 交互轮数压缩增益：$$\text{TCG} = \frac{T_{\text{Slow}} - T_{\text{Fast}}}{T_{\text{Slow}}} \times 100\% \ge 50\%$$。

### 2. [Persona 画像与主/支线建模规范](specs/persona_spec.md) `[基础规范]`
- 规范 Persona 静态画像（职业、语言风格、身份背景）与动态画像（主线业务、支线保障、突发事件、干扰项池）。
- 保证生成的人物多样性、真实性与参数合理性。

## 六、 文档维护与更新准则

1. **唯一真值原则**：
   - 系统整体思路与需求基准以顶层设计文档为依归；新特性演进以 `specs/cognitive_memory_dev_spec.md` 为唯一准则；`archive/` 仅保留历史排查与演进背景，杜绝冗余重复。
2. **命名规范**：
   - 英文小写结合下划线，避免中文空格与特殊符号（历史顶层文档保留原名以保障兼容性）。
3. **去戏谑化命名**：
   - 所有技术文档统一使用**“双轨成败分支模拟评测”**或**“动态多分支模拟评测”**，严禁使用非正式名词。
4. **语言风格**：
   - 业务台词示例全量使用大白话，严禁出现生硬生僻的底层网络工程黑话（如“空口切片”、“相控阵天线”）。
5. **Mermaid 制图规范**：
   - 纯白底色 (`#FFFFFF`)、全量加粗文字、加粗线条（`stroke-width: 2px`）。
