单据融合对话的记忆机制核心思路（概要）

为了让模型在“75% 网元单据 + 25% 自然语言对话”中既听得懂用户的口语代称，又能准确拿到历史档位、时长和场馆预热规则，采用“工作记忆 + 结构化事实记忆 + 场馆经验记忆”三层架构，并通过“向量相似度检索与同行槽位提取 + 二阶段关联表补全”完成检索（查看示例 →）。核心参考论文可归纳为三类：

① 记忆分哪几层存：工作记忆、事实记忆与经验记忆各司其职 —— 参考 Mem0、A-MEM、DCPM
  • 工作记忆（管当前会话）：保存最近几轮对话上下文、待填槽位表、时间冲突标记与慢路径澄清挂起状态，工单闭环后即释放。
  • 结构化事实记忆（管客观单据与固定习惯）：按结构化字段存储历史网元实测单据、常驻周期偏好（periodic_preference）、主辅业务映射（service_to_app）以及用户个性化表述映射（expression）。
  • 场馆与排障经验记忆（管踩坑总结）：将前序网元异常（如 PRB=96% 拥塞降级）复盘得出的补偿动作（如“五棵松演唱会自动提前 20 分钟预热并升至 P0”）存为带触发条件的经验规则。
② 记忆怎么查得准：向量相似度检索与同行槽位提取 + 二阶段关联表补全 —— 参考 LoCoMo-Plus、RHELM、A-MEM
  • 向量相似度检索与同行槽位提取：用 text-embedding-v4 对用户口语提问做向量检索，定位到候选记录后，直接读取同一行里的 venue、priority、duration 等结构化槽位列，不做脆弱的正则切词。
  • 二阶段关联表补全：第一跳拿到主业务或场馆后，第二跳自动通过 service_to_app 与 periodic_preference 把绑定的后台辅业务（如网盘上传）和场馆经验规则一并查出来。
  • 否定子句分离与权重衰减过滤：当用户说“别用上次卡顿那回”时，先拆分否定子句，将带负向特征（sla_degraded）的记录做权重衰减过滤，防止因字面词重合误召回。
③ 记忆怎么写进去与更新：重复门限、回执校准与新状态覆盖 —— 参考 PersonaMem-v3、LongMemEval、Mem0
  • 多次重复才记为长期习惯：1~2 次偶发单据只留在单据流水表；只有同一时间规律与档位连续出现 ≥ 3 次，才写入 periodic_preference 长期偏好表。
  • 断流子单合并与无效废单过滤：入库前自动过滤 1 分钟内退订的 aborted 废单，并将隧道/电梯断流重连切碎的相邻子单合并还原为完整单据。
  • 实测回执校准与冲突覆盖：业务结束后以网元实测回执更新实际时长与网络状态；当用户升级设备或更改习惯时，将旧记录标为 superseded，默认只检索最新有效记录。

核心维度 影响因子与业务定义 参考论文
1. 三层记忆分层存储 工作记忆、结构化事实记忆与经验记忆解耦
当轮对话状态存工作记忆，历史网元单据与常驻周期偏好存事实表，异常排障与预热补偿规则存经验表		 • Mem0：将对话状态、长期事实记忆与图结构关联分层维护。
• DCPM：分离管理用户的长期稳定偏好与当前会话的短期上下文状态。
个性化表述映射层（expression）
将用户的口语代称（如“去崇礼钻山洞那段”）与网元单据标准名称（京礼高速隧道群）建立双向绑定		 • LoCoMo-Plus：解决用户口语提问与底层历史记录字面不一致的语义对齐问题。
• PersonaMem-v3：构建用户专属口语习惯到标准业务实体的映射记忆。
2. 混合检索与同行槽位提取 向量相似度检索与同行槽位提取
通过稠密向量定位候选记录行，命中后直接读取同行结构化槽位列（venue、priority、duration），兼顾语义泛化与参数精确性		 • A-MEM：每条记忆卡片同时包含自然语言描述向量与结构化属性标签，检索命中后直接提取结构化属性。
• RHELM：结合非结构化对话语义与结构化工单字段进行联合检索。
二阶段关联表补全
第一跳命中场馆或主业务后，第二跳通过 service_to_app 与 periodic_preference 自动补全关联的后台辅业务与场馆预热经验		 • A-MEM / Mem0：利用记忆节点间的双向链接与关系图谱，在第一跳召回后按关联关系拉取关联记忆。
3. 否定过滤与抗混淆 否定子句分离与权重衰减过滤
识别查询中的排除指代（如“不是卡顿那次”），对命中负向状态的候选单据做权重衰减过滤，避免相似单据混淆		 • RHELM：针对同地点多条相似事件，结合正负特征约束进行精确区分。
4. 写入门控与数据清洗 多次重复才记为长期习惯（≥ 3 次）
单据流水中连续出现 ≥ 3 次相同规律才晋升写入长期周期表，偶发单据仅保留在流水层		 • PersonaMem-v3：通过多次重复出现的行为证据归纳长期稳定习惯，过滤偶发噪声。
断线重连子单合并与无效单过滤
入库前过滤 aborted 退订废单及日常未开保障的短流量，并将断网重连切碎的相邻子单据合并为一条完整记录		 • RHELM：对原始事件流先做有效性清洗与连续片段合并，再写入长期记忆库。
5. 状态覆盖与参数合成 新状态覆盖旧状态与多源参数优先级合成
用最新单据或网元实测回执覆盖旧记录；合成参数时按“当前显式指令 > 突发事件 > 场馆经验 > 日常默认”顺序执行		 • LongMemEval：通过时间戳与版本号管理记忆状态更新，确保检索时以最新状态为准。
• Mem0：通过 ADD / UPDATE / DELETE / NOOP 四类动作自动消解新旧记忆冲突。
