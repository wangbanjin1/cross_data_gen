一、两篇论文的主要工作

Mem0（Prateek Chhikara 等发表，arXiv:2504.19413v1）与 A-MEM（Rutgers 大学 Wujiang Xu 等发表，arXiv:2502.12110v11）是当前开源社区与学术界最常用的两类 Agent 外部记忆架构，分别聚焦于动态增量记忆维护（增删改）与交互经验的结构化卡片组织：

论文名称与链接 核心工作与技术机制 优势与局限性对比
Mem0
arXiv:2504.19413v1 (2025) 		包含“提取（Extraction）”与“更新（Update）”两阶段管线：每轮对话后提取候选事实，先在向量库中检索相似旧记忆，再由工具调用决定执行 ADD（新增）、UPDATE（修改最新值）、DELETE（删除矛盾旧值）或 NOOP（跳过）。 优势：比全量拼接长上下文节省 90%+ token 延迟；
局限：若仅靠自然语言短句向量检索而缺少结构化槽位列，在高频数值参数变更场景下容易召回已淘汰的相似旧句。
A-MEM
arXiv:2502.12110v11 (2025) 		借鉴卡片盒笔记法（Zettelkasten），每次交互后为新记忆生成包含上下文描述、关键词标签、属性字段的结构化卡片（Note），并自动与历史相关卡片建立双向链接并触发已有卡片的总结演进。 优势：非常适合把多轮排障或纠偏交互沉淀为带触发标签的“经验卡片”；
局限：每次写入均调用大模型更新多张邻接卡片，写入开销较高。

二、对记忆机制与自演进设计的参考

① 借鉴 Mem0 的增量更新动作，但增加“左侧结构化字段列”
在事实记忆维护中保留了 ADD / EDIT / REMOVE 的状态更新思路，但将应用、业务、画质、时延、时间窗拆为规整的结构化列，只对右侧 4~10 字的口语短词建向量，避免纯文本向量检索把旧档位误召回。
② 借鉴 A-MEM 的结构化卡片思想构建“经验记忆表”
当网元异常单据引发后续复盘对话后，将排障结论浓缩为带触发条件标签（condition）与具体参数修正动作（suggested_adjustments）的经验卡，实现从多轮澄清慢路径到单轮快路径的自演进。
