一、论文的主要工作

DCPM（Memory Beyond Recall: A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents，Tianxiang Fei 等发表，arXiv:2606.09483v1）指出：当前 Agent 记忆系统把“状态修改更新”、“因果关联”和“跨事件规律归纳”全部混在同一个平面检索库里，导致遇到用户习惯随时间演变或临时变动时极易召回过时信息。为此，论文借鉴认知心理学的双过程理论（Dual-Process Theory），提出了分层双过程认知记忆架构。

二、System 1 与 System 2 双过程机制拆解

处理过程 核心工作机制 解决的典型错误场景
System 1：同步状态修正与版本链 (Daytime Writer) 每次新事件或对话发生时，不直接覆盖删除旧记录，也不平铺堆放，而是建立 supersedes（新覆盖旧）双向版本链，明确标记当前哪个版本处于生效状态。 解决“用户已经把画质从 720p 升级到 1080p，但向量检索仍把半年前的 720p 旧记录搜出来当成当前偏好”的问题。
System 2：异步跨事件模式归纳 (Nighttime Engine) 在后台异步扫描累计的多条原始记录与状态链，将重复出现的行为提炼为领域模式（Domain Schemas），并区分“单次临时变动”与“长期稳定偏好转变”。 解决“用户平时固定在园区用 1080p，某天因为暴雨临时降为 720p，结果系统把单次临时降级误当成永久习惯修改”的问题。

三、对“单据融合对话”故事线与三层记忆架构的参考

① 区分“单次临时变动”与“长期档位升级”
参考 DCPM 的设计，在故事线中同时构造了“因突发天气/临时差旅产生的单次参数变动（事后恢复原习惯）”与“因设备升级产生的长期档位覆盖”，检验系统能否正确区分临时单据与长期偏好更新。
② 从高频原始单据中异步归纳周期与习惯
参考 System 2 的异步模式归纳机制，网元实时上报的单据先存入工作记忆流水表；当同一规律连续出现 ≥ 3 次时，再归纳提炼进事实记忆表（periodic_preference / preferred_value）。
